Cyber Incident Analytics Model

A public-data security analytics project focused on ingestion architecture, incident modeling, and interactive Power BI reporting. Claims are framed as portfolio scope rather than production security outcomes.

Interactive Power BI Report

Problem

Incident data is useful only when it can be sliced by vector, geography, timing, and severity without manual spreadsheet work.

Build

Modeled a cloud-style flow from raw public data into structured analytical tables suitable for BI consumption.

Delivery

Designed report views for recurring exploit patterns, regional concentration, and incident filtering workflows.

What This Demonstrates

  • Translating security-domain questions into dimensions, facts, and report filters.
  • Published semantic model around a CYBER_THREATS fact table with risk, loss, geography, vulnerability, and attack dimensions.
  • Thinking through ingestion, storage, transformation, and BI delivery boundaries.
  • Presenting risk-oriented data without overstating production impact.
