Case Study

E-Commerce Behavior Report

Public REES46 e-commerce behavior data transformed into an exploratory BI report focused on scale, shaping, filtering, and report usability.

  • REES46 public dataset
  • 135M rows
  • Python
  • Power Query
  • Power BI

Interactive Power BI Report

Large Power BI embeds can take time to load depending on Microsoft Power BI traffic and browser resources.

Problem

High-volume event logs make it hard to understand browsing, cart, category, and purchase behavior without a modeled report layer.

Build

Used Python and Power Query to shape a large public dataset into reportable fields and interactive filters.

Delivery

Created a Power BI experience for exploring categories, brands, event types, and conversion-related behavior.

Technical Focus

  • Handling large flat behavioral data and reducing it into report-friendly structures.
  • Published report structure: seven pages spanning overview, products, categories, brands, and user/product exploration.
  • Designing filters that let analysts move from overview to product/category detail.
  • Documenting model-size and performance constraints for a large public BI file.
