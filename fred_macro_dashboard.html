Federal Reserve Economic Data - Powered Macroeconomic Insights Dashboard

Interactive 3 - Page Power BI Dashboard's

Why it matters: This full-stack ETL and analytics pipeline empowers stakeholders with a near-real-time view of key U.S. economic indicators like inflation, GDP, home prices, unemployment, and retail growth. Designed for decision-makers, hiring managers, and general economics enthusiasts.

🔍 Business Need

Hiring managers, recruiters, and the general public often struggle to interpret raw economic data. This dashboard makes the data accessible, visual, and meaningful by transforming macro indicators into insights.

🧱 Tech Stack

Azure Databricks · Delta Lake · Apache Spark · FRED API · Power BI (Fabric) · DAX · GitHub

⚙️ Architecture Overview

  • ETL: Modular Databricks notebooks ingest FRED data daily/monthly/quarterly → save to Delta
  • Modeling: Star schema with DimDate, fact_macro_daily, fact_macro_monthly, fact_macro_quarterly
  • Delivery: Semantic model in Power BI; SQL tables exposed via Delta → Fabric
  • CI/CD: Pull request workflow with tracked commits on GitHub

🧠 Economic Health Score (Z-Score Normalized DAX)

Econ_Health_Score_4Factor =
VAR Z_GDP   = ( GDP - AVG(GDP) ) / STDEV(GDP)
VAR Z_Prof  = ( Profits - AVG(Profits) ) / STDEV(Profits)
VAR Z_CPI   = ( CPI - AVG(CPI) ) / STDEV(CPI)
VAR Z_Unemp = ( Unemp - AVG(Unemp) ) / STDEV(Unemp)
RETURN
( Z_GDP + Z_Prof - Z_CPI - Z_Unemp ) / 4

This DAX measure quantifies “macro health” on a normalized scale. Higher values = better conditions (GDP ↑, Profits ↑, CPI ↓, Unemployment ↓).
