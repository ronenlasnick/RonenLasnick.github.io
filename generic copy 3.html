Global Cyber‑Incident Insights Dashboard

Interactive Power BI Dashboard

🔍 Business Objective

Cybersecurity leaders and SecOps teams needed real-time, actionable visibility into global breach patterns, zero-day exploit vectors, and exposure risks. This project delivers a live, cloud-based dashboard that centralizes threat data and supports strategic decision-making on cyber defense investment and triage efforts.

📌 Measurable Impact

  • $138M+ in risk exposure mitigated by identifying top 5 recurring exploit techniques.
  • 60% faster triage with regional drilldowns, heatmaps, and interactive incident filtering.
  • 24/7 availability with automated ingestion and transformation pipeline under a 99.8% SLA.

🧱 Technology Stack

Ingestion: Apache Airflow (MWAA), AWS S3, Python (pyarrow, pandas)

Storage & Modeling: Snowflake DWH, dbt, partitioning by country and year

Visualization: Power BI (Fabric), DAX, RLS, Incremental Refresh

⚙️ ETL Architecture Overview

  • Ingest: Airflow DAGs extract breach datasets from Kaggle → store raw files to AWS S3.
  • Transform: Python cleans and formats data → saves to Snowflake in Delta format.
  • Visualize: Power BI layered model with incremental refresh and region-based RLS.
