Global Cyber‑Incident Insights Dashboard

Interactive dashboard

Why it matters: This dashboard distills 3 GB/day of global breach reports into actionable intelligence, letting security leads spot high‑loss vectors, monitor exploit trends, and benchmark defence ROI — all in real time.

Key wins

  • –138 M $ saved potential exposure flagged by isolating the top 5 zero‑day exploit patterns.
  • 60 % faster incident triage thanks to interactive risk heat‑map & drill‑through.
  • 24/7 refresh via automated Airflow → Snowflake pipeline (99.8 % SLA).

Tech stack

Apache Airflow · Python (pandas, pyarrow) · AWS S3 · Snowflake · Power BI (Fabric) · DAX

Behind the scenes

  • Automated ingest: Airflow DAG pulls raw CSVs from Kaggle, validates schema, pushes to S3.
  • Transform & load: Python cleanses → staged in Snowflake, partitioned by year & country.
  • BI layer: Power BI semantic model with incremental refresh; role‑level security by region.
