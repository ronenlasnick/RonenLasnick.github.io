Global Cyber Incident Insights Dashboard

This end-to-end data project provides interactive insights into global cyber threats, combining a robust cloud-based ETL pipeline with business intelligence to support real-time analysis and strategic decision-making.

Project Overview:

The dashboard analyzes cyber incidents across industries and countries, with a focus on financial impact, risk levels, attack durations, exploited vulnerabilities, and the effectiveness of defense mechanisms.

Key Features:

• Global Impact Overview: Treemap visualization of affected populations and financial loss per user by country.

• Risk-Level Industry Breakdown: Comparison of high vs. low risk financial impact by industry and attack type.

• Attack Duration Analysis: Country-level analysis of how attack duration correlates with financial loss.

• Vulnerability & Exploit Profiling: Highlights vulnerabilities such as zero-day and unpatched software.

• Defense Strategy Insights: Evaluates the effectiveness of firewalls, encryption, AI-based detection, and more.

Full Data Engineering Pipeline:

• Data Collection: Orchestrated with Apache Airflow, using a custom DAG to automatically pull raw cyber incident data from Kaggle.

• Transformation in Python: Cleaned and processed using Python for consistency and reliability.

• Cloud Staging: Transformed datasets are uploaded and stored in Amazon S3.

• Production Warehouse: Final data is loaded into Snowflake, which serves as the centralized data warehouse for analytics.

• Business Intelligence Layer: Microsoft Fabric (Power BI) is connected to Snowflake and set up with daily scheduled refreshes, ensuring the dashboard is always up to date.

Tools & Technologies Used:

Apache Airflow, Python, Kaggle, Amazon S3, Snowflake, Power BI, Microsoft Fabric This project showcases advanced data engineering, ETL orchestration, and BI visualization—bridging raw data to meaningful insights with an automated, scalable architecture.
