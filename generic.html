E‑commerce Behaviour Dashboard

Interactive Power BI Dashboard

🔍 Business Need

Retail teams often lack clear, real-time visibility into what drives abandoned carts, seasonal demand spikes, or brand-level performance. This dashboard turns 135M rows of clickstream and transaction data into clear visual insights decision-makers can act on fast.

📌 Key Wins

  • Identified high‑margin items with ≥15 % conversion uplift potential → informed targeted promo plan.
  • Flagged low‑stock SKUs driving ‑7 % weekly lost sales → fed to replenishment pipeline.
  • Drill‑through filters by brand and category reduced SQL-based ad-hoc requests by ~6 hrs/week.

🧱 Tech Stack

Python (pandas · pyarrow) for cleaning & optimization → Power Query → Power BI for interactive storytelling.

📂 Dataset Info

REES46 e‑commerce behaviour dataset (Kaggle) · 135M rows · 14 columns · Oct 2019 – Apr 2020 · Size: 57 GB
