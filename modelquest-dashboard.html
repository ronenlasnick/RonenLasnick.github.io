Case Study

ModelQuest AI Model Trends

A metadata analytics project that turns public AI model information into a trend report. The case study demonstrates data wrangling, metric definition, and visual storytelling for a fast-moving technical domain.

  • Python
  • pandas
  • Power Query
  • DAX
  • Power BI

Interactive Power BI Report

Problem

AI model releases are hard to compare without normalized metadata around timing, family, parameters, and training effort.

Build

Curated and shaped public metadata into fields suitable for time-series and model-family comparison.

Delivery

Built an interactive report for launch cadence, model growth, and efficiency-oriented comparisons.

Technical Focus

  • Metadata normalization for model families, release years, and training-related measures.
  • Published report structure: main analytical page plus tooltip pages for richer inspection.
  • DAX measures for trend comparison and report-level storytelling.
  • Clear report interactions for a technical audience.
